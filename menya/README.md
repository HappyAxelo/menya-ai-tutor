# Menya web app

React + Vite front end for Menya. See the [main README](../README.md) for what it does, and
[docs/DEPLOYMENT.md](../docs/DEPLOYMENT.md) to run or deploy it.

```bash
npm install
npm run dev       # developer mode unless VITE_SUPABASE_URL / VITE_SUPABASE_ANON_KEY are set
npm run build
npm run eval      # live tutoring evaluation (GROQ_API_KEY in .env)
```
